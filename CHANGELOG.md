# Changelog

## 1.0.0 - 2026-11-19

First public version.

- Heat maps for 2.4, 5 and 6 GHz: signal, serving AP, SINR, data rate, APs in range
- Floor plan import (PNG/JPG) with wall, outline and balcony detection; building width read from the
  dimensions on the drawing
- Wall editor with five materials, area tools for outdoor zones and cut-outs
- AP models, channel planning, position optimiser
- Devices with speed test (CSMA/CA simulation), neighbouring networks and microwaves as interferers
- Multiple floors, variants, calibration from measurements
- Print/PDF report, PNG export, project files
