Wi-Fi Planner

Estimates Wi-Fi coverage for a building from its floor plan, walls and access points. Everything runs locally in the browser.

  1. Building: pick an example or import a floor plan (PNG/JPG, or drop it onto the map). Walls, outline and width are detected.
  2. Scale: if the width is off, use "Measure scale" under "Building" and click a known distance.
  3. Access points: drag them, or use "Optimise positions" and "Find minimum".
  4. Devices: place PCs, laptops and TVs and run a speed test per device.
  5. Result: print a report, save the map as an image or save the project.
